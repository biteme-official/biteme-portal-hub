# 주간 성과 보고 v2 개편 방향

## 현재 구조 (v1)
- 월간 스코어카드 (채널별 누적/목표/달성률)
- 주간 추이 테이블 (W1~W4)
- 액션 입력 (영향 지표 드롭다운 + 텍스트)
- AI 분석 요인 (긍정/부정/유지 별도 섹션)

→ 각 섹션이 분리되어 있어 숫자-원인-액션 연결이 끊김

## 개편 방향 (v2)

### 2단 구조

**1. KPI 스코어카드 (상단)**
- 월간 목표 달성률 요약 (공헌이익 등 상위 KPI)
- 현재 v1 스코어카드와 유사한 역할
- "목표 대비 어디쯤인지" 한눈에 보는 용도

**2. 키메트릭 카드 (하단, 지표별 반복)**
- 각 키메트릭(자사몰, 스마트스토어, 쿠팡 등)이 독립된 카드
- 카드 안에 아래 요소가 하나의 흐름으로 구성:

```
[키메트릭: 자사몰]
  이번주 600만 | 전주 550만 | +9.1%
  Q3 마일스톤: 3,000만 중 2,250만 (75%)
  ▸ 주간추이 (접힘: W1~W4 테이블)
  💡 AI 요인: 시즌 기획전 효과로 +9.1% 상승
  → 추천 액션: 기획전 2차 배너 교체
  → (내 액션 입력)
```

### 핵심 변경점

1. **숫자→요인→액션 통합**: 키메트릭별로 `실적 → AI 요인(왜?) → 추천 액션(그래서 뭐?)` 한 카드에 묶음
2. **KPI vs 키메트릭 분리**: 스코어카드는 KPI(상위), 카드는 키메트릭(채널별 실행 단위)
3. **분기 마일스톤 추가**: 키메트릭 카드에 Q 목표 대비 진척 프로그레스바
4. **주간 추이 접힘 처리**: 기본 뷰는 이번주 숫자+요인+액션에 집중, 펼치면 W1~W4 확인

## 조직 구조 (2026-09-07)

본부 > 팀 > 개인 3단 구조. 팀별로 지표 성격이 다름.

| 팀 | metricKind | 목표 주기 | 데이터 출처 |
|---|---|---|---|
| 브랜드팀 | currency (채널 매출/공헌이익) | 월간 | Tableau/Sheets 연동 예정 |
| 경영지원팀 | percent (Key Metric 달성률) | **분기** | 담당자 주간 수기 입력 |
| CS팀 | 미정 | 미정 | 미정 |

- `ChannelData.kind` 로 currency/percent 분기 렌더
- `lowerIsBetter` 지표(캐시플로우 목표편차, 고정비 효율화율)는 달성률 역산
- `improveCount` / `stallCount` — 정체 3회 이상 시 재도출 대상 표시 (KPI-Action Cycle G2)
- 경영지원팀은 2026년 9월(3Q)부터 신규 입력 시작. 2~7월 엑셀 이력은 이관하지 않음
